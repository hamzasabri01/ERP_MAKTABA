# Chapitre 1 : Contexte general du projet

## Presentation du projet

SecureERP Cloud est un projet de deploiement et de securisation d'une application ERP Web dans une infrastructure Cloud privee locale.

## Presentation de ProERP Web

ProERP Web est une application ERP Web composee d'un frontend React/Vite, d'un backend FastAPI et d'une base SQLite.

## Objectifs specifiques

- Etudier les principes du Cloud Computing prive.
- Concevoir une architecture technique securisee.
- Deployer ProERP Web sur Ubuntu Server.
- Mettre en place Nginx comme reverse proxy.
- Securiser les acces avec UFW et Fail2ban.
- Mettre en place le monitoring et les sauvegardes.

## Perimetre

Le projet couvre le deploiement local, la securisation de base, la supervision et le plan de sauvegarde/restauration.
