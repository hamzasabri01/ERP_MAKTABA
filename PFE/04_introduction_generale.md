# Introduction generale

Les entreprises utilisent de plus en plus des applications Web pour gerer leurs activites quotidiennes. Les applications ERP centralisent les donnees commerciales, les stocks, les ventes, les achats et les utilisateurs. Leur hebergement doit donc garantir la disponibilite du service, la securite des acces et la protection des donnees.

Dans ce contexte, le projet SecureERP Cloud vise a transformer l'application ProERP Web en une solution deployable dans une infrastructure Cloud privee locale, basee sur des outils libres.

**Problematique :** Comment concevoir et deployer une infrastructure Cloud privee securisee, supervisee et resiliente permettant d'heberger une application ERP Web tout en garantissant la protection des donnees, la disponibilite du service et la maitrise des couts ?

**Objectif general :** Mettre en place une infrastructure Cloud privee basee sur des outils open source pour heberger l'application ProERP Web dans un environnement securise, supervise et sauvegarde.
