# Resume

Ce projet presente la conception, le deploiement et la securisation d'une infrastructure Cloud privee destinee a heberger une application ERP Web appelee ProERP Web. La solution, nommee SecureERP Cloud, repose sur des outils open source: Ubuntu Server, Docker, Docker Compose, Nginx, UFW, Fail2ban, Netdata et des scripts de sauvegarde.

L'objectif est de proposer une architecture securisee, supervisee et resiliente, adaptee a un contexte pedagogique et professionnel.

# Abstract

This project presents the design, deployment and hardening of a private cloud infrastructure used to host a web ERP application named ProERP Web. The proposed solution, SecureERP Cloud, relies on open-source tools such as Ubuntu Server, Docker, Docker Compose, Nginx, UFW, Fail2ban, Netdata and backup scripts.

The objective is to provide a secure, monitored and resilient architecture suitable for an academic and professional context.
