# Script de soutenance

Bonjour, je vais presenter mon projet de fin d'etudes intitule: Conception, deploiement et securisation d'une infrastructure Cloud privee pour l'hebergement d'une application ERP Web.

Le projet porte le nom SecureERP Cloud. Il consiste a deployer l'application ProERP Web dans une infrastructure locale basee sur Ubuntu Server, Docker, Nginx et des outils open source de securite et de supervision.

La problematique est la suivante: comment heberger une application ERP Web dans un Cloud prive tout en garantissant la securite, la disponibilite et la maitrise des couts ?

La solution proposee s'appuie sur une machine virtuelle Ubuntu, Docker Compose, un reverse proxy Nginx, UFW, Fail2ban, Netdata et un systeme de sauvegarde automatise.

Les tests realises concernent l'acces a l'application, l'API, le reverse proxy, le pare-feu, Fail2ban, Netdata, la sauvegarde et la restauration.

En conclusion, SecureERP Cloud fournit une base professionnelle et evolutive pour heberger ProERP Web dans un environnement prive, securise et supervise.
